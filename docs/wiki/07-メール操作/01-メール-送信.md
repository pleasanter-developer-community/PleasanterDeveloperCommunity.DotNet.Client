## 概要

APIを使用してアイテムに関連するメールを送信します。

## 対応バージョン

- プリザンター 1.2.4.0以降
    - Attachments（添付ファイル）機能が追加されたバージョン
- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## SendMailAsync

```csharp
Task<ApiResponse<SendMailResponse>> SendMailAsync(
    long itemId,
    SendMailRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## 使用例

### メールを送信

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Mails;

var request = new SendMailRequest
{
    To = "recipient@example.com",
    Title = "テストメール",
    Body = "これはテストメールです。"
};

var result = await client.SendMailAsync(itemId: 123, request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine("メールを送信しました");
}
```

### CCとBCCを含めたメール送信

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Mails;

var request = new SendMailRequest
{
    To = "recipient@example.com",
    Cc = "cc@example.com",
    Bcc = "bcc@example.com",
    Title = "重要なお知らせ",
    Body = "詳細な内容をこちらに記載します。"
};

var result = await client.SendMailAsync(itemId: 123, request: request);
```

### 添付ファイル付きメール送信

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Mails;

// ファイルをBase64エンコード
var fileBytes = await File.ReadAllBytesAsync("sample.txt");
var base64Content = Convert.ToBase64String(fileBytes);

var request = new SendMailRequest
{
    To = "recipient@example.com",
    Title = "添付ファイル付きメール",
    Body = "添付ファイルをご確認ください。",
    Attachments = new List<MailAttachment>
    {
        new MailAttachment
        {
            Name = "sample.txt",
            Base64 = base64Content,
            ContentType = "text/plain"
        }
    }
};

var result = await client.SendMailAsync(itemId: 123, request: request);
```
