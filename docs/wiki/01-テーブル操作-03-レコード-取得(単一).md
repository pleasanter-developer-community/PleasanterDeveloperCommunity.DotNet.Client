## 概要

指定したレコードIDのレコードを1件取得します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## GetRecordAsync

```csharp
Task<ApiResponse<RecordResponse>> GetRecordAsync(
    long recordId,
    GetRecordRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## 使用例

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Items;

// リクエストモデルを使用した取得
var request = new GetRecordRequest
{
    View = new View
    {
        GridColumns = new List<string> { "Title", "Body", "ClassA" }
    }
};

var record = await client.GetRecordAsync(recordId: 123, request: request);
```
