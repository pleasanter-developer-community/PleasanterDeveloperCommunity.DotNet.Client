# レコード作成 - items/{siteId}/create <!-- omit in toc -->

## 概要

指定したサイトに新しいレコードを作成します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## メソッド

```csharp
Task<ApiResponse<CreateRecordResponse>> CreateRecordAsync(
    long siteId,
    CreateRecordRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## パラメータ

| 引数                | 型                    | 必須 | 説明                   |
| ------------------- | --------------------- | :--: | ---------------------- |
| `siteId`            | `long`                | Yes  | サイトID               |
| `request`           | `CreateRecordRequest` | Yes  | リクエストモデル       |
| `timeout`           | `TimeSpan?`           |      | リクエストタイムアウト |
| `cancellationToken` | `CancellationToken`   |      | キャンセルトークン     |

## 使用例

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Items;

// リクエストモデルを使用した作成
var request = new CreateRecordRequest
{
    Title = "タイトル",
    Body = "内容",
    Status = 100,
    ClassHash = new Dictionary<string, string>
    {
        { "ClassA", "分類A" }
    },
    NumHash = new Dictionary<string, decimal>
    {
        { "NumA", 123.45m }
    }
};

var result = await client.CreateRecordAsync(siteId: 456, request: request);
```
