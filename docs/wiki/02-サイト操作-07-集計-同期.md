# 集計の同期 - sites/{siteId}/synchronizesummaries <!-- omit in toc -->

## 概要

APIを使用してサイトの集計を同期します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 制限事項

- サイトの管理権限が必要です

## メソッド

```csharp
Task<ApiResponse<SynchronizeSummariesResponse>> SynchronizeSummariesAsync(
    long siteId,
    SynchronizeSummariesRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## パラメータ

| 引数                | 型                            | 必須 | 説明                   |
| ------------------- | ----------------------------- | :--: | ---------------------- |
| `siteId`            | `long`                        | Yes  | サイトID               |
| `request`           | `SynchronizeSummariesRequest` | Yes  | リクエストモデル       |
| `timeout`           | `TimeSpan?`                   |      | リクエストタイムアウト |
| `cancellationToken` | `CancellationToken`           |      | キャンセルトークン     |

## 使用例

### 集計を同期

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Sites;

var request = new SynchronizeSummariesRequest();
var result = await client.SynchronizeSummariesAsync(siteId: 123, request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine("集計を同期しました");
}
```
