APIリクエストの作成方法について説明します。

## 基本的なリクエスト処理

```csharp
// シンプルなリクエスト（パラメータ直接指定）
var response = await client.GetRecordAsync(siteId: 123, recordId: 456);

// リクエストモデルを使用
var request = new CreateRecordRequest
{
    Title = "新しいレコード",
    Body = "レコードの説明",
    Status = 100,
    ClassHash = new Dictionary<string, string>
    {
        ["ClassA"] = "分類値A"
    }
};

var response = await client.CreateRecordAsync(siteId: 123, request);
```

## リクエストの構造

すべてのリクエストモデルは`ApiRequestBase`を継承しています。

### ApiRequestBaseプロパティ

| プロパティ   | 型       | 説明                                              |
| ------------ | -------- | ------------------------------------------------- |
| `ApiVersion` | `string` | APIバージョン（PleasanterClient作成時に自動設定） |
| `ApiKey`     | `string` | APIキー（PleasanterClient作成時に自動設定）       |

> **Note**: `ApiVersion`と`ApiKey`はクライアント作成時に設定されるため、リクエストモデルで指定する必要はありません。

### リクエストモデルの名前空間

| 名前空間                   | 説明                                     |
| :------------------------- | :--------------------------------------- |
| `Models.Requests.Items`    | テーブル・レコード操作のリクエストモデル |
| `Models.Requests.Sites`    | サイト操作のリクエストモデル             |
| `Models.Requests.Users`    | ユーザ操作のリクエストモデル             |
| `Models.Requests.Groups`   | グループ操作のリクエストモデル           |
| `Models.Requests.Depts`    | 組織操作のリクエストモデル               |
| `Models.Requests.Binaries` | 添付ファイル操作のリクエストモデル       |
| `Models.Requests.Mails`    | メール送信のリクエストモデル             |
| `Models.Requests.Extended` | 拡張SQL実行のリクエストモデル            |
| `Models.Requests.Sessions` | セッション操作のリクエストモデル         |

## 主要なリクエストモデル

### CreateRecordRequest

レコード作成に使用します。

| プロパティ        | 型                                         | 説明         |
| ----------------- | ------------------------------------------ | ------------ |
| `Title`           | `string`                                   | タイトル     |
| `Body`            | `string`                                   | 本文         |
| `Status`          | `int`                                      | 状態         |
| `Manager`         | `int`                                      | 管理者ID     |
| `Owner`           | `int`                                      | 担当者ID     |
| `CompletionTime`  | `string`                                   | 完了日時     |
| `ClassHash`       | `Dictionary<string, string>`               | 分類項目     |
| `NumHash`         | `Dictionary<string, decimal>`              | 数値項目     |
| `DateHash`        | `Dictionary<string, DateTime>`             | 日付項目     |
| `DescriptionHash` | `Dictionary<string, string>`               | 説明項目     |
| `CheckHash`       | `Dictionary<string, bool>`                 | チェック項目 |
| `AttachmentsHash` | `Dictionary<string, List<AttachmentData>>` | 添付ファイル |
| `ProcessId`       | `int`                                      | プロセスID   |
| `ImageHash`       | `Dictionary<string, ImageSettings>`        | 画像設定     |

### 使用例

```csharp
var request = new CreateRecordRequest
{
    Title = "課題: ログイン機能の実装",
    Body = "ユーザー認証機能を実装する",
    Status = 100,
    Manager = 1,
    Owner = 2,
    ClassHash = new Dictionary<string, string>
    {
        ["ClassA"] = "開発",
        ["ClassB"] = "高優先"
    },
    NumHash = new Dictionary<string, decimal>
    {
        ["NumA"] = 8.5m  // 見積工数
    },
    DateHash = new Dictionary<string, DateTime>
    {
        ["DateA"] = DateTime.Now.AddDays(7)  // 期限
    },
    CheckHash = new Dictionary<string, bool>
    {
        ["CheckA"] = true  // レビュー必要
    }
};

var response = await client.CreateRecordAsync(siteId, request);
```

## ビュー設定（View）

レコード一覧取得時のフィルタやソートを指定します。

### Viewプロパティ

| プロパティ                  | 型                                           | 説明                     |
| --------------------------- | -------------------------------------------- | ------------------------ |
| `Incomplete`                | `bool`                                       | 未完了のみ取得           |
| `Own`                       | `bool`                                       | 自分が担当のみ取得       |
| `NearCompletionTime`        | `bool`                                       | 期限が近いもののみ取得   |
| `Delay`                     | `bool`                                       | 遅延しているもののみ取得 |
| `Overdue`                   | `bool`                                       | 期限超過のもののみ取得   |
| `Search`                    | `string`                                     | 全文検索キーワード       |
| `ColumnFilterHash`          | `Dictionary<string, string>`                 | 列フィルタ設定           |
| `ColumnFilterSearchTypes`   | `Dictionary<string, ColumnFilterSearchType>` | フィルタ検索タイプ       |
| `ColumnFilterNegatives`     | `List<string>`                               | 否定フィルタ対象列       |
| `ColumnSorterHash`          | `Dictionary<string, SortOrderType>`          | ソート設定               |
| `ApiDataType`               | `ApiDataType`                                | APIデータタイプ          |
| `ApiColumnKeyDisplayType`   | `ApiColumnKeyDisplayType`                    | カラムキー表示タイプ     |
| `ApiColumnValueDisplayType` | `ApiColumnValueDisplayType`                  | カラム値表示タイプ       |
| `GridColumns`               | `List<string>`                               | 返却する項目を制御       |

### 使用例

```csharp
var view = new View
{
    Incomplete = true,
    Own = true,
    ColumnFilterHash = new Dictionary<string, string>
    {
        ["ClassA"] = "[\"開発\"]",
        ["Status"] = "[\"100\",\"150\"]"
    },
    ColumnSorterHash = new Dictionary<string, SortOrderType>
    {
        ["CompletionTime"] = SortOrderType.Asc
    },
    GridColumns = new List<string>
    {
        "ResultId", "Title", "Status", "ClassA", "CompletionTime"
    }
};

var response = await client.GetRecordsAsync(siteId, view: view);
```

## 添付ファイルの設定

### FileHelperを使用した添付

ファイルパスから直接添付データを作成できます。

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Helpers;

var request = new CreateRecordRequest
{
    Title = "添付ファイル付きレコード",
    AttachmentsHash = new Dictionary<string, List<AttachmentData>>
    {
        ["AttachmentsA"] = new List<AttachmentData>
        {
            FileHelper.ToAttachmentData(@"C:\docs\specification.pdf"),
            FileHelper.ToAttachmentData(@"C:\images\diagram.png")
        }
    }
};

var response = await client.CreateRecordAsync(siteId, request);
```

### 手動での添付データ作成

```csharp
var attachmentData = new AttachmentData
{
    Name = "document.pdf",
    Base64 = Convert.ToBase64String(File.ReadAllBytes(@"C:\docs\document.pdf")),
    ContentType = "application/pdf"
};

var request = new CreateRecordRequest
{
    Title = "手動設定の添付ファイル",
    AttachmentsHash = new Dictionary<string, List<AttachmentData>>
    {
        ["AttachmentsA"] = new List<AttachmentData> { attachmentData }
    }
};
```

## メール送信リクエスト

### SendMailRequestプロパティ

| プロパティ    | 型                     | 説明                           |
| ------------- | ---------------------- | ------------------------------ |
| `From`        | `string`               | 送信元（Mail.jsonのFixedFrom） |
| `To`          | `string`               | 宛先                           |
| `Cc`          | `string`               | CC                             |
| `Bcc`         | `string`               | BCC                            |
| `Title`       | `string`               | 件名                           |
| `Body`        | `string`               | 本文                           |
| `Attachments` | `List<MailAttachment>` | 添付ファイル                   |

### 使用例

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Helpers;

var request = new SendMailRequest
{
    To = "recipient@example.com",
    Cc = "manager@example.com",
    Title = "月次レポート送付",
    Body = "月次レポートを添付にて送付いたします。",
    Attachments = new List<MailAttachment>
    {
        FileHelper.ToMailAttachment(@"C:\reports\monthly-report.xlsx")
    }
};

var response = await client.SendMailAsync(recordId, request);
```
