ファイルからBase64エンコードやContentType判定を行うヘルパー機能について説明します。

## 概要

`FileHelper` クラスは添付ファイルを扱う際に便利な静的ヘルパーメソッドを提供しています。

- ファイル → Base64/ContentType 変換
- Base64 → ファイル保存
- `MailAttachment` / `AttachmentData` インスタンスの作成

## FileHelper

ファイルからBase64エンコードやContentType判定を行う静的ヘルパークラスです。

### メソッド一覧

| メソッド                         | 説明                                              |
| -------------------------------- | ------------------------------------------------- |
| `ToBase64`                       | ファイルをBase64エンコード                        |
| `GetContentType`                 | ファイルパスからContentTypeを推測                 |
| `GetContentTypeFromExtension`    | 拡張子からContentTypeを推測                       |
| `GetFileData`                    | Base64とContentTypeをタプルで取得                 |
| `GetFullFileData`                | FileName、Size、Base64、ContentTypeをタプルで取得 |
| `AddMapping`                     | カスタムContentTypeマッピングを追加               |
| `SaveFromBase64`                 | Base64をデコードしてファイルに保存（同期）        |
| `SaveFromBase64Async`            | Base64をデコードしてファイルに保存（非同期）      |
| `ToBytes`                        | Base64をデコードしてバイト配列を取得              |
| `SaveFromBase64ToDirectory`      | Base64をデコードしてディレクトリに保存（同期）    |
| `SaveFromBase64ToDirectoryAsync` | Base64をデコードしてディレクトリに保存（非同期）  |
| `ToMailAttachment`               | ファイルからMailAttachmentを作成                  |
| `ToAttachmentData`               | ファイルからAttachmentDataを作成                  |

### ToBase64

ファイルをBase64エンコードして返します。

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Helpers;

var base64 = FileHelper.ToBase64(@"C:\path\to\file.pdf");
```

### GetContentType

ファイルパスからContentTypeを推測します。700種類以上の拡張子に対応しています。

```csharp
var contentType = FileHelper.GetContentType(@"C:\path\to\document.pdf");
// "application/pdf"

var contentType = FileHelper.GetContentType(@"C:\path\to\image.png");
// "image/png"

var contentType = FileHelper.GetContentType(@"C:\path\to\unknown.xyz");
// "application/octet-stream"（不明な拡張子）
```

### GetContentTypeFromExtension

拡張子からContentTypeを推測します。

```csharp
var contentType = FileHelper.GetContentTypeFromExtension(".xlsx");
// "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
```

### GetFileData

Base64とContentTypeを同時に取得します。

```csharp
var (base64, contentType) = FileHelper.GetFileData(@"C:\path\to\file.pdf");
// base64: "JVBERi0xLjQK..."
// contentType: "application/pdf"
```

### GetFullFileData

ファイル名、サイズ、Base64、ContentTypeを同時に取得します。MailAttachmentやAttachmentDataのファクトリメソッドで内部的に使用されています。

```csharp
var (fileName, size, base64, contentType) = FileHelper.GetFullFileData(@"C:\path\to\file.pdf");
// fileName: "file.pdf"
// size: 12345 (バイト)
// base64: "JVBERi0xLjQK..."
// contentType: "application/pdf"
```

### AddMapping

カスタム拡張子のContentTypeマッピングを追加します。

```csharp
// カスタム拡張子を追加
FileHelper.AddMapping(".custom", "application/x-custom");

// 以降は .custom 拡張子で "application/x-custom" が返される
var contentType = FileHelper.GetContentType("file.custom");
// "application/x-custom"
```

### SaveFromBase64 / SaveFromBase64Async

Base64文字列をデコードしてファイルに保存します。保存先ディレクトリが存在しない場合は自動的に作成されます。

```csharp
// 同期版
FileHelper.SaveFromBase64(base64String, @"C:\output\document.pdf");

// 非同期版
await FileHelper.SaveFromBase64Async(base64String, @"C:\output\document.pdf");

// APIから取得したBase64を保存する例
var response = await client.GetBinaryAsync(siteId, guid);
if (response.IsSuccess && response.Response?.Base64 != null)
{
    await FileHelper.SaveFromBase64Async(
        response.Response.Base64,
        @"C:\downloads\attachment.pdf");
}
```

### ToBytes

Base64文字列をデコードしてバイト配列を取得します。

```csharp
var bytes = FileHelper.ToBytes(base64String);
// bytesをStreamに変換したり、他の処理に使用
```

### SaveFromBase64ToDirectory / SaveFromBase64ToDirectoryAsync

Base64文字列をデコードして指定ディレクトリにファイル名を指定して保存します。保存先パスを返します。

```csharp
// 同期版
var savedPath = FileHelper.SaveFromBase64ToDirectory(
    base64String,
    @"C:\downloads",
    "document.pdf");
// savedPath: "C:\downloads\document.pdf"

// 非同期版
var savedPath = await FileHelper.SaveFromBase64ToDirectoryAsync(
    base64String,
    @"C:\downloads",
    "document.pdf");
```

### ToMailAttachment

ファイルパスからMailAttachmentインスタンスを作成します。

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Helpers;
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Mails;

// ファイルから直接作成
var attachment = FileHelper.ToMailAttachment(@"C:\path\to\document.pdf");
// Name, Base64, ContentType が自動設定される

// メール送信リクエストで使用
var request = new SendMailRequest
{
    To = "recipient@example.com",
    Title = "添付ファイル付きメール",
    Body = "添付ファイルをご確認ください。",
    Attachments = new List<MailAttachment>
    {
        FileHelper.ToMailAttachment(@"C:\docs\report.pdf"),
        FileHelper.ToMailAttachment(@"C:\images\chart.png")
    }
};

await client.SendMailAsync(recordId, request);
```

### ToAttachmentData

ファイルパスからAttachmentDataインスタンスを作成します。

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Helpers;
using VehicleVision.Pleasanter.DotNet.Client.Models.Common;

// ファイルから直接作成
var attachment = FileHelper.ToAttachmentData(@"C:\path\to\document.pdf");
// Name, Size, Base64, ContentType が自動設定される

// レコード作成リクエストで使用
var request = new CreateRecordRequest
{
    Title = "添付ファイル付きレコード",
    AttachmentsHash = new Dictionary<string, List<AttachmentData>>
    {
        ["AttachmentsA"] = new List<AttachmentData>
        {
            FileHelper.ToAttachmentData(@"C:\docs\manual.pdf"),
            FileHelper.ToAttachmentData(@"C:\images\diagram.png")
        }
    }
};

await client.CreateRecordAsync(siteId, request);
```

## 使用例

### メール送信（複数添付ファイル）

```csharp
var request = new SendMailRequest
{
    To = "user@example.com",
    Title = "月次レポート",
    Body = "月次レポートを送付いたします。",
    Attachments = new List<MailAttachment>
    {
        FileHelper.ToMailAttachment(@"C:\reports\monthly.xlsx"),
        FileHelper.ToMailAttachment(@"C:\reports\chart.png")
    }
};

await client.SendMailAsync(recordId, request);
```

### レコード作成（添付ファイル付き）

```csharp
var request = new CreateRecordRequest
{
    Title = "プロジェクト資料",
    Body = "プロジェクトに関する資料です。",
    AttachmentsHash = new Dictionary<string, List<AttachmentData>>
    {
        ["AttachmentsA"] = new List<AttachmentData>
        {
            FileHelper.ToAttachmentData(@"C:\docs\spec.pdf")
        },
        ["AttachmentsB"] = new List<AttachmentData>
        {
            FileHelper.ToAttachmentData(@"C:\images\mockup.png")
        }
    }
};

await client.CreateRecordAsync(siteId, request);
```

### レコード更新（添付ファイル追加）

```csharp
var request = new UpdateRecordRequest
{
    AttachmentsHash = new Dictionary<string, List<AttachmentData>>
    {
        ["AttachmentsA"] = new List<AttachmentData>
        {
            FileHelper.ToAttachmentData(@"C:\docs\updated.pdf")
        }
    }
};

await client.UpdateRecordAsync(siteId, recordId, request);
```

### 添付ファイルの取得とダウンロード

```csharp
// 添付ファイル情報を取得
var response = await client.GetBinaryAsync(guid);

if (response.IsSuccess && response.Response != null)
{
    var attachment = response.Response;

    // Base64からバイト配列を取得
    var bytes = attachment.GetBytes();

    // ファイルに保存（同期）
    attachment.SaveToFile(@"C:\downloads\document.pdf");

    // ファイルに保存（非同期）
    await attachment.SaveToFileAsync(@"C:\downloads\document.pdf");

    // ディレクトリ指定で元のファイル名で保存（同期）
    attachment.SaveToDirectory(@"C:\downloads");

    // ディレクトリ指定で元のファイル名で保存（非同期）
    await attachment.SaveToDirectoryAsync(@"C:\downloads");
}
```

> **Note**: AttachmentResponseクラスの`GetBytes()`、`SaveToFile()`、`SaveToFileAsync()`メソッドは内部でFileHelperを使用しています。

## 注意事項

### ファイルサイズ

大きなファイルはBase64エンコードによりサイズが約1.33倍になります。プリザンターの設定やサーバーの制限に注意してください。

### ファイルの存在確認

ファイルが存在しない場合は `FileNotFoundException` がスローされます。

```csharp
try
{
    var attachment = FileHelper.CreateMailAttachment(@"C:\nonexistent.pdf");
}
catch (FileNotFoundException ex)
{
    Console.WriteLine($"ファイルが見つかりません: {ex.FileName}");
}
```

### 対応ContentType

`Microsoft.AspNetCore.StaticFiles` の `FileExtensionContentTypeProvider` を使用しており、700種類以上の拡張子に対応しています。未対応の拡張子は `application/octet-stream` として扱われます。
