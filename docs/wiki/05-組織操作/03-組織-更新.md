## 概要

APIを使用して既存の組織情報を更新します。

- テナント管理者権限が必要です

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## UpdateDeptAsync

```csharp
Task<ApiResponse<UpdateDeptResponse>> UpdateDeptAsync(
    long deptId,
    UpdateDeptRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

### パラメータ

| プロパティ#1        | #2         | 型                  | 必須 | 説明                   |
| ------------------- | ---------- | ------------------- | :--: | ---------------------- |
| `deptId`            |            | `long`              | Yes  | 組織ID                 |
| `request`           |            | `UpdateDeptRequest` | Yes  | リクエストモデル       |
|                     | `DeptCode` | `string?`           |      | 組織コード             |
|                     | `DeptName` | `string?`           |      | 組織名                 |

|                     | `Disabled` | `bool?`             |      | 無効                   |
| `timeout`           |            | `TimeSpan?`         |      | リクエストタイムアウト |
| `cancellationToken` |            | `CancellationToken` |      | キャンセルトークン     |

## 使用例

### シンプルな更新

```csharp
var result = await client.UpdateDeptAsync(
    deptId: 123,
    deptName: "新しい組織名");

if (result.IsSuccess)
{
    Console.WriteLine("組織情報を更新しました");
}
```

### リクエストモデルを使用した更新

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Depts;

var request = new UpdateDeptRequest
{
    DeptCode = "DEV002",
    DeptName = "開発第2部",
    Body = "更新後の説明"
};

var result = await client.UpdateDeptAsync(123, request);

if (result.IsSuccess)
{
    Console.WriteLine("組織情報を更新しました");
}
```
