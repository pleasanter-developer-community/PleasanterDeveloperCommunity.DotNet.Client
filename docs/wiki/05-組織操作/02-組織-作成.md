## 概要

APIを使用して新しい組織を作成します。

- テナント管理者権限が必要です

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

    CancellationToken cancellationToken = default)

## 使用例

### シンプルな組織作成

```csharp
var result = await client.CreateDeptAsync(
    deptCode: "DEV001",
    deptName: "開発部",
    body: "ソフトウェア開発部門");

if (result.IsSuccess)
{
    Console.WriteLine($"作成された組織ID: {result.Response?.Id}");
}
```

### リクエストモデルを使用した作成

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Depts;

var request = new CreateDeptRequest
{
    DeptCode = "SALES001",
    DeptName = "営業部",
    Body = "営業部門",
    Disabled = false
};

var result = await client.CreateDeptAsync(request);

if (result.IsSuccess)
{
    Console.WriteLine($"作成された組織ID: {result.Response?.Id}");
}
```
