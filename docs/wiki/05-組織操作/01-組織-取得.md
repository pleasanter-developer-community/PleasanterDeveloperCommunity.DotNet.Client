## 概要

APIを使用して組織一覧を取得します。

- テナント管理者権限が必要です

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 使用例

### 全組織を取得

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Depts;

var request = new GetDeptsRequest();
var result = await client.GetDeptsAsync(request);

if (result.IsSuccess)
{
    foreach (var dept in result.Response?.Data ?? new List<DeptData>())
    {
        Console.WriteLine($"組織: {dept.DeptName} ({dept.DeptCode})");
    }
}
```

### フィルタを使用

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Depts;

var request = new GetDeptsRequest
{
    Offset = 0,
    View = new View
    {
        ColumnFilterHash = new Dictionary<string, string>
        {
            { "Disabled", "false" }
        }
    }
};

var result = await client.GetDeptsAsync(request);
```
