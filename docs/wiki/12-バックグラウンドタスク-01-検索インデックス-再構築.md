## 概要

APIを使用して検索インデックスを再構築します。全サイトまたは特定のサイトを対象に再構築を実行できます。

この機能を利用するには、プリザンターのパラメータ設定で `BackgroundTask.Enabled` を有効にする必要があります。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 使用例

```csharp
// 全サイトの検索インデックスを再構築
var result = await client.RebuildAllSearchIndexesAsync();

if (result.IsSuccess)
{
    Console.WriteLine($"メッセージ: {result.Response?.Message}");
}

// 特定サイトの検索インデックスを再構築
var result2 = await client.RebuildSearchIndexesAsync(siteId: 123);

if (result2.IsSuccess)
{
    Console.WriteLine($"メッセージ: {result2.Response?.Message}");
}

// リクエストモデルを使用
var request = new RebuildSearchIndexesRequest();
var result3 = await client.RebuildAllSearchIndexesAsync(request);

if (result3.IsSuccess)
{
    Console.WriteLine($"メッセージ: {result3.Response?.Message}");
}
```
