## 概要

APIを使用してセッションデータを削除します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## セッションの有効期限

| 保存モード                          | 有効期限                                               |
| ----------------------------------- | ------------------------------------------------------ |
| 通常（`SavePerUser: false`）        | `RetentionPeriod`（デフォルト1440分=24時間）経過後削除 |
| ユーザー単位（`SavePerUser: true`） | 期限切れによる自動削除の対象外（永続化）               |

- 通常モードのセッションは自動削除されますが、明示的に削除することも可能です
- ユーザー単位モードのセッションは自動削除されないため、不要になった場合は明示的に削除する必要があります

## DeleteSessionAsync

```csharp
Task<ApiResponse<DeleteSessionResponse>> DeleteSessionAsync(
    DeleteSessionRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

### パラメータ

| プロパティ#1        | #2            | 型                     | 必須 | 説明                                                                  |
| ------------------- | ------------- | ---------------------- | :--: | --------------------------------------------------------------------- |
| `request`           |               | `DeleteSessionRequest` | Yes  | リクエストモデル                                                      |
|                     | `SessionKey`  | `string?`              | Yes  | セッションキー                                                        |
|                     | `SavePerUser` | `bool`                 |      | ユーザー単位で保存されたセッションを削除するか（デフォルト: `false`） |
| `timeout`           |               | `TimeSpan?`            |      | リクエストタイムアウト                                                |
| `cancellationToken` |               | `CancellationToken`    |      | キャンセルトークン                                                    |

### レスポンス

| プロパティ#1 | #2       | 型                           | 説明             |
| ------------ | -------- | ---------------------------- | ---------------- |
| `StatusCode` |          | `int`                        | ステータスコード |
| `Message`    |          | `string?`                    | メッセージ       |
| `Response`   |          | `DeleteSessionResponseData?` | レスポンスデータ |
|              | `UserId` | `int`                        | ユーザーID       |
|              | `Key`    | `string?`                    | セッションキー   |

## 使用例

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Sessions;

// 通常モード（セッションGUID単位）で削除
var request = new DeleteSessionRequest
{
    SessionKey = "MySessionKey"
};
var result = await client.DeleteSessionAsync(request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine("セッションを削除しました");
}

// ユーザー単位で保存されたセッションを削除
var userRequest = new DeleteSessionRequest
{
    SessionKey = "MyUserSessionKey",
    SavePerUser = true
};
var userResult = await client.DeleteSessionAsync(request: userRequest);
```
