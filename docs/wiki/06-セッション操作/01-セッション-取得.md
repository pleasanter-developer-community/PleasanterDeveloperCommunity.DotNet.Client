## 概要

APIを使用してセッションデータを取得します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## セッションの有効期限

| 保存モード                          | 有効期限                                               |
| ----------------------------------- | ------------------------------------------------------ |
| 通常（`SavePerUser: false`）        | `RetentionPeriod`（デフォルト1440分=24時間）経過後削除 |
| ユーザー単位（`SavePerUser: true`） | 期限切れによる自動削除の対象外（永続化）               |

- 通常モードでは、セッションはセッションGUID単位で保存され、`Session.json`の`RetentionPeriod`で設定された期間経過後に日次で削除されます
- ユーザー単位モードでは、セッションはユーザーID単位で保存され、明示的に削除しない限り永続化されます

## GetSessionAsync

```csharp
Task<ApiResponse<GetSessionResponse>> GetSessionAsync(
    GetSessionRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

### パラメータ

| プロパティ#1        | #2            | 型                  | 必須 | 説明                                                                  |
| ------------------- | ------------- | ------------------- | :--: | --------------------------------------------------------------------- |
| `request`           |               | `GetSessionRequest` | Yes  | リクエストモデル                                                      |
|                     | `SessionKey`  | `string?`           | Yes  | セッションキー                                                        |
|                     | `SavePerUser` | `bool`              |      | ユーザー単位で保存されたセッションを取得するか（デフォルト: `false`） |
| `timeout`           |               | `TimeSpan?`         |      | リクエストタイムアウト                                                |
| `cancellationToken` |               | `CancellationToken` |      | キャンセルトークン                                                    |

### レスポンス

| プロパティ#1 | #2       | 型                        | 説明             |
| ------------ | -------- | ------------------------- | ---------------- |
| `StatusCode` |          | `int`                     | ステータスコード |
| `Message`    |          | `string?`                 | メッセージ       |
| `Response`   |          | `GetSessionResponseData?` | レスポンスデータ |
|              | `UserId` | `int`                     | ユーザーID       |
|              | `Key`    | `string?`                 | セッションキー   |
|              | `Value`  | `string?`                 | セッション値     |

## 使用例

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Sessions;

// 通常モード（セッションGUID単位）で取得
var request = new GetSessionRequest
{
    SessionKey = "MySessionKey"
};
var result = await client.GetSessionAsync(request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine($"Key: {result.Data.Response?.Key}");
    Console.WriteLine($"Value: {result.Data.Response?.Value}");
}

// ユーザー単位で保存されたセッションを取得
var userRequest = new GetSessionRequest
{
    SessionKey = "MyUserSessionKey",
    SavePerUser = true
};
var userResult = await client.GetSessionAsync(request: userRequest);
```
