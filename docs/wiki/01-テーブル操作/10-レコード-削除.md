## 概要

指定したレコードIDのレコードを削除します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## DeleteRecordAsync

```csharp
Task<ApiResponse<DeleteRecordResponse>> DeleteRecordAsync(
    long recordId,
    DeleteRecordRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

### パラメータ

| プロパティ#1        | #2  | 型                    | 必須 | 説明                                |
| ------------------- | --- | --------------------- | :--: | ----------------------------------- |
| `recordId`          |     | `long`                | Yes  | レコードID（IssueIdまたはResultId） |
| `request`           |     | `DeleteRecordRequest` | Yes  | リクエストモデル                    |
| `timeout`           |     | `TimeSpan?`           |      | リクエストタイムアウト              |
| `cancellationToken` |     | `CancellationToken`   |      | キャンセルトークン                  |

### レスポンス

`ApiResponse<DeleteRecordResponse>` を返却します。

| プロパティ#1 | #2               | 型                      | 説明                       |
| ------------ | ---------------- | ----------------------- | -------------------------- |
| `StatusCode` |                  | `HttpStatusCode`        | HTTPステータスコード       |
| `Message`    |                  | `string?`               | レスポンスメッセージ       |
| `Response`   |                  | `DeleteRecordResponse?` | レスポンスデータ           |
|              | `Id`             | `long`                  | 削除されたレコードID       |
|              | `StatusCode`     | `int`                   | ステータスコード           |
|              | `Message`        | `string?`               | メッセージ                 |
|              | `LimitPerDate`   | `int?`                  | 1日あたりのAPI呼び出し上限 |
|              | `LimitRemaining` | `int?`                  | 残りのAPI呼び出し回数      |
| `IsSuccess`  |                  | `bool`                  | 成功したかどうか           |

## 使用例

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Items;

// リクエストモデルを使用した削除
var request = new DeleteRecordRequest();

var result = await client.DeleteRecordAsync(recordId: 12345, request: request);

if (result.IsSuccess)
{
    Console.WriteLine($"削除されたレコードID: {result.Response?.Id}");
}
```

### タイムアウトを指定した削除

```csharp
var result = await client.DeleteRecordAsync(
    recordId: 12345,
    request: new DeleteRecordRequest(),
    timeout: TimeSpan.FromSeconds(30)
);

if (result.IsSuccess)
{
    Console.WriteLine($"削除されたレコードID: {result.Response?.Id}");
}
else
{
    Console.WriteLine($"エラー: {result.Message}");
}
```

## 注意事項

- 削除したレコードは復元できません。削除前に十分確認してください。
- 適切な権限がない場合、削除操作は失敗します。
- 他のレコードからリンクされている場合、関連する参照も解除されます。
