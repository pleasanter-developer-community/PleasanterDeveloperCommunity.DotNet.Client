## 概要

キーに基づいてレコードを作成または更新します。キーに一致するレコードが存在する場合は更新、存在しない場合は新規作成します。

> **Warning**: プリザンター内部でのUpsert処理は、レコードの存在確認（Get）→作成/更新（Create/Update）の間でロックを取得していません。そのため、**同一Keysで短期間に連続してUpsertを発行すると、存在判定のタイミングによりレースコンディションが発生し、重複作成や例外が発生する可能性があります**。同一キーに対する並列実行が想定される場合は、クライアント側で適切な排他制御を実施してください。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 使用例

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Items;

// リクエストモデルを使用した作成・更新
var request = new UpsertRecordRequest
{
    Keys = new List<string> { "ClassA" },
    Title = "タイトル",
    ClassHash = new Dictionary<string, string>
    {
        { "ClassA", "キー値" }
    }
};

var result = await client.UpsertRecordAsync(siteId: 456, request: request);
```
