## 概要

APIを使用して拡張機能を削除します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 制限事項

- サービス管理者権限が必要です

## DeleteExtensionAsync

```csharp
Task<ApiResponse<DeleteExtensionResponse>> DeleteExtensionAsync(
    long extensionId,
    DeleteExtensionRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

### パラメータ

| プロパティ#1        | #2  | 型                       | 必須 | 説明                   |
| ------------------- | --- | ------------------------ | :--: | ---------------------- |
| `extensionId`       |     | `long`                   | Yes  | 拡張機能ID             |
| `request`           |     | `DeleteExtensionRequest` | Yes  | リクエストモデル       |
| `timeout`           |     | `TimeSpan?`              |      | リクエストタイムアウト |
| `cancellationToken` |     | `CancellationToken`      |      | キャンセルトークン     |

### レスポンス

| プロパティ#1 | 型        | 説明             |
| ------------ | --------- | ---------------- |
| `StatusCode` | `int`     | ステータスコード |
| `Message`    | `string?` | メッセージ       |

## 使用例

### 拡張機能を削除

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Extensions;

var request = new DeleteExtensionRequest();
var result = await client.DeleteExtensionAsync(extensionId: 123, request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine("拡張機能を削除しました");
}
```
