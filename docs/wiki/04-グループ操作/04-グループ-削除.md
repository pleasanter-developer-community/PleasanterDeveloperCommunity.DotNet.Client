## 概要

APIを使用してグループを削除します。

**制限事項**: テナント管理者権限が必要です。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## DeleteGroupAsync

```csharp
Task<ApiResponse<DeleteGroupResponse>> DeleteGroupAsync(
    long groupId,
    DeleteGroupRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

### パラメータ

| プロパティ#1        | #2  | 型                   | 必須 | 説明                   |
| ------------------- | --- | -------------------- | :--: | ---------------------- |
| `groupId`           |     | `long`               | Yes  | グループID             |
| `request`           |     | `DeleteGroupRequest` | Yes  | リクエストモデル       |
| `timeout`           |     | `TimeSpan?`          |      | リクエストタイムアウト |
| `cancellationToken` |     | `CancellationToken`  |      | キャンセルトークン     |

### レスポンス

| プロパティ   | 型        | 説明                 |
| ------------ | --------- | -------------------- |
| `Id`         | `int`     | 削除されたグループID |
| `StatusCode` | `int`     | ステータスコード     |
| `Message`    | `string?` | メッセージ           |

## 使用例

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Groups;

var request = new DeleteGroupRequest();
var result = await client.DeleteGroupAsync(groupId: 123, request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine("グループを削除しました");
}
```
