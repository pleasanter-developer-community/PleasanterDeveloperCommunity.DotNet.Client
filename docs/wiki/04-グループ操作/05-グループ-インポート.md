## 概要

CSVファイルをインポートして、グループを一括で作成・更新します。

**制限事項**: テナント管理者権限が必要です。

**注意事項**: 既存のグループは `GroupName` をキーとして更新されます。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## ImportGroupsAsync (byte[]版)

```csharp
Task<ApiResponse<ImportGroupsResponse>> ImportGroupsAsync(
    byte[] csvData,
    string fileName,
    Encoding? encoding = null,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

### パラメータ

| プロパティ#1        | 型                  | 必須 | 説明                                                                                                             |
| ------------------- | ------------------- | :--: | ---------------------------------------------------------------------------------------------------------------- |
| `csvData`           | `byte[]`            | Yes  | CSVファイルのバイナリデータ                                                                                      |
| `fileName`          | `string`            | Yes  | ファイル名                                                                                                       |
| `encoding`          | `Encoding?`         |      | CSVファイルのエンコーディング（`Encoding.UTF8` または `Encoding.GetEncoding(932)`、デフォルト: `Encoding.UTF8`） |
| `timeout`           | `TimeSpan?`         |      | リクエストタイムアウト                                                                                           |
| `cancellationToken` | `CancellationToken` |      | キャンセルトークン                                                                                               |

### レスポンス

| プロパティ   | 型        | 説明             |
| ------------ | --------- | ---------------- |
| `Id`         | `int`     | ID               |
| `StatusCode` | `int`     | ステータスコード |
| `Message`    | `string?` | メッセージ       |

## CSVフォーマット

CSVファイルには以下の列を含めることができます：

| 列名        | 説明       | 必須 |
| ----------- | ---------- | :--: |
| `GroupName` | グループ名 | Yes  |
| `Body`      | 説明       |      |
| `Disabled`  | 無効フラグ |      |

## 使用例

```csharp
// ファイルパスを直接指定してインポート（推奨）
// encodingを省略するとファイル内容から自動判定
var result = await client.ImportGroupsFromFileAsync(
    filePath: @"C:\data\groups.csv");

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine($"メッセージ: {result.Data.Message}");
}

// byte[]版でのインポート
var csvData = File.ReadAllBytes("groups.csv");
var result2 = await client.ImportGroupsAsync(
    csvData: csvData,
    fileName: "groups.csv");

// Stream版でのインポート
using var fileStream = File.OpenRead(@"C:\data\groups.csv");
var result3 = await client.ImportGroupsAsync(
    csvStream: fileStream,
    fileName: "groups.csv");

// Shift-JISエンコーディングでインポート
var csvDataSjis = File.ReadAllBytes("groups_sjis.csv");
var result4 = await client.ImportGroupsAsync(
    csvData: csvDataSjis,
    fileName: "groups_sjis.csv",
    encoding: Encoding.GetEncoding(932));
```
