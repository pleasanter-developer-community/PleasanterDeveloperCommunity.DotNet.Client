## 概要

APIを使用してグループ一覧を取得します。

**制限事項**: テナント管理者権限が必要です。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 使用例

```csharp
var result = await client.GetGroupsAsync(new GetGroupsRequest());

if (result.IsSuccess)
{
    foreach (var group in result.Response?.Data ?? new List<GroupData>())
    {
        Console.WriteLine($"グループ: {group.GroupName}");
    }
}
```
