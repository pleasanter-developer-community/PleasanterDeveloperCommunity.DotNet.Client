# 組織の取得 - depts/get <!-- omit in toc -->

## 概要

APIを使用して組織一覧を取得します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 制限事項

- テナント管理者権限が必要です

## メソッド

```csharp
Task<ApiResponse<GetDeptsResponse>> GetDeptsAsync(
    GetDeptsRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## パラメータ

| 引数                | 型                  | 必須 | 説明                   |
| ------------------- | ------------------- | :--: | ---------------------- |
| `request`           | `GetDeptsRequest`   | Yes  | リクエストモデル       |
| `timeout`           | `TimeSpan?`         |      | リクエストタイムアウト |
| `cancellationToken` | `CancellationToken` |      | キャンセルトークン     |

## レスポンス

`DeptData` には以下のプロパティが含まれます：

| プロパティ | 型        | 説明       |
| ---------- | --------- | ---------- |
| `DeptId`   | `int`     | 組織ID     |
| `DeptCode` | `string?` | 組織コード |
| `DeptName` | `string?` | 組織名     |
| `Body`     | `string?` | 内容       |
| `Disabled` | `bool`    | 無効フラグ |

## 使用例

### 全組織を取得

```csharp
var result = await client.GetDeptsAsync();

if (result.Data?.StatusCode == 200)
{
    foreach (var dept in result.Data.Response?.Data ?? new List<DeptData>())
    {
        Console.WriteLine($"組織: {dept.DeptName} ({dept.DeptCode})");
    }
}
```
