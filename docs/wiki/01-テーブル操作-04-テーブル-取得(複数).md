## 概要

指定したサイトIDの複数レコードを取得します。ページングに対応しています。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

    long siteId,
    GetRecordsRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)

## GetAllRecordsAsync

すべてのレコードを取得します（ページングを自動処理）。

```csharp
Task<ApiResponse<RecordsResponse>> GetAllRecordsAsync(
    long siteId,
    GetRecordsRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## 使用例

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Items;

// リクエストモデルを使用した取得
var request = new GetRecordsRequest
{
    Offset = 0,
    View = new View
    {
        ColumnFilterHash = new Dictionary<string, string>
        {
            { "ClassA", "検索値" }
        }
    }
};

var records = await client.GetRecordsAsync(siteId: 456, request: request);
```

### ビュー設定を使用した取得

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests;

var request = new GetRecordsRequest
{
    View = new View
    {
        ColumnFilterHash = new Dictionary<string, string>
        {
            { "ClassA", "検索値" }
        },
        ColumnSorterHash = new Dictionary<string, SortOrderType>
        {
            { "CreatedTime", SortOrderType.Desc }
        }
    }
};

var records = await client.GetRecordsAsync(siteId: 456, request: request);
```
