## 概要

APIを使用して新しいユーザを作成します。

- テナント管理者権限が必要です

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## CreateUserAsync

```csharp
    CreateUserRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## 使用例

### シンプルなユーザ作成

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Users;

var request = new CreateUserRequest
{
    LoginId = "user001",
    Name = "テストユーザ",
    Password = "Password123!"
};

var result = await client.CreateUserAsync(request);

if (result.IsSuccess)
{
    Console.WriteLine($"作成されたユーザID: {result.Response?.Id}");
}
```

### 詳細な情報を指定して作成

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Users;

var request = new CreateUserRequest
{
    LoginId = "user002",
    Name = "詳細ユーザ",
    Password = "Password123!",
    UserCode = "U002",
    DeptId = 1,
    TenantManager = false,
    AllowApi = true,
    MailAddresses = new List<string> { "user002@example.com" }
};

var result = await client.CreateUserAsync(request);
```
