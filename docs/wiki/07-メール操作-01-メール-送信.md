# メールの送信 - items/{itemId}/mails/send <!-- omit in toc -->

## 概要

APIを使用してアイテムに関連するメールを送信します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## メソッド

```csharp
Task<ApiResponse<SendMailResponse>> SendMailAsync(
    long itemId,
    SendMailRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## パラメータ

| 引数                | 型                  | 必須 | 説明                   |
| ------------------- | ------------------- | :--: | ---------------------- |
| `itemId`            | `long`              | Yes  | アイテムID             |
| `request`           | `SendMailRequest`   | Yes  | リクエストモデル       |
| `timeout`           | `TimeSpan?`         |      | リクエストタイムアウト |
| `cancellationToken` | `CancellationToken` |      | キャンセルトークン     |

## 使用例

### メールを送信

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Mails;

var request = new SendMailRequest
{
    To = "recipient@example.com",
    Title = "テストメール",
    Body = "これはテストメールです。"
};

var result = await client.SendMailAsync(itemId: 123, request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine("メールを送信しました");
}
```

### CCとBCCを含めたメール送信

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Mails;

var request = new SendMailRequest
{
    To = "recipient@example.com",
    Cc = "cc@example.com",
    Bcc = "bcc@example.com",
    Title = "重要なお知らせ",
    Body = "詳細な内容をこちらに記載します。"
};

var result = await client.SendMailAsync(itemId: 123, request: request);
```
