# 組織の削除 - depts/{deptId}/delete <!-- omit in toc -->

## 概要

APIを使用して組織を削除します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 制限事項

- テナント管理者権限が必要です
- 所属するユーザがいる場合は削除できません

## メソッド

```csharp
Task<ApiResponse<DeleteDeptResponse>> DeleteDeptAsync(
    long deptId,
    DeleteDeptRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## パラメータ

| 引数                | 型                  | 必須 | 説明                   |
| ------------------- | ------------------- | :--: | ---------------------- |
| `deptId`            | `long`              | Yes  | 組織ID                 |
| `request`           | `DeleteDeptRequest` | Yes  | リクエストモデル       |
| `timeout`           | `TimeSpan?`         |      | リクエストタイムアウト |
| `cancellationToken` | `CancellationToken` |      | キャンセルトークン     |

## 使用例

### 組織を削除

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Depts;

var request = new DeleteDeptRequest();
var result = await client.DeleteDeptAsync(deptId: 123, request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine("組織を削除しました");
}
```
