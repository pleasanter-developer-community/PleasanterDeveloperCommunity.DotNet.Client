## 概要

APIを使用して組織を削除します。

- テナント管理者権限が必要です
- 所属するユーザがいる場合は削除できません

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 使用例

### 組織を削除

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Depts;

var request = new DeleteDeptRequest();
var result = await client.DeleteDeptAsync(deptId: 123, request: request);

if (result.IsSuccess)
{
    Console.WriteLine("組織を削除しました");
}
else
{
    Console.WriteLine($"エラー: {result.Message}");
}
```
