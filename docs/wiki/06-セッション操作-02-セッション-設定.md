## 概要

APIを使用してセッションデータを設定します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## セッションの有効期限

| 保存モード                          | 有効期限                                               |
| ----------------------------------- | ------------------------------------------------------ |
| 通常（`SavePerUser: false`）        | `RetentionPeriod`（デフォルト1440分=24時間）経過後削除 |
| ユーザー単位（`SavePerUser: true`） | 期限切れによる自動削除の対象外（永続化）               |

- 通常モードでは、セッションはセッションGUID単位で保存され、`Session.json`の`RetentionPeriod`で設定された期間経過後に日次で削除されます
- ユーザー単位モードでは、セッションはユーザーID単位で保存され、明示的に削除しない限り永続化されます

## SetSessionAsync

```csharp
Task<ApiResponse<SetSessionResponse>> SetSessionAsync(
    SetSessionRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

### パラメータ

| プロパティ#1        | #2             | 型                  | 必須 | 説明                                            |
| ------------------- | -------------- | ------------------- | :--: | ----------------------------------------------- |
| `request`           |                | `SetSessionRequest` | Yes  | リクエストモデル                                |
|                     | `SessionKey`   | `string?`           | Yes  | セッションキー                                  |
|                     | `SessionValue` | `string?`           | Yes  | セッション値                                    |
|                     | `SavePerUser`  | `bool`              |      | ユーザー単位で保存するか（デフォルト: `false`） |
| `timeout`           |                | `TimeSpan?`         |      | リクエストタイムアウト                          |
| `cancellationToken` |                | `CancellationToken` |      | キャンセルトークン                              |

### レスポンス

| プロパティ#1 | #2       | 型                        | 説明             |
| ------------ | -------- | ------------------------- | ---------------- |
| `StatusCode` |          | `int`                     | ステータスコード |
| `Message`    |          | `string?`                 | メッセージ       |
| `Response`   |          | `SetSessionResponseData?` | レスポンスデータ |
|              | `UserId` | `int`                     | ユーザーID       |
|              | `Key`    | `string?`                 | セッションキー   |

## 使用例

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Sessions;

// 通常モード（セッションGUID単位）で保存
var request = new SetSessionRequest
{
    SessionKey = "MySessionKey",
    SessionValue = "MySessionValue"
};
var result = await client.SetSessionAsync(request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine("セッションを設定しました");
}

// ユーザー単位で保存（永続化）
var userRequest = new SetSessionRequest
{
    SessionKey = "MyUserSessionKey",
    SessionValue = "MyUserSessionValue",
    SavePerUser = true
};
var userResult = await client.SetSessionAsync(request: userRequest);
```
