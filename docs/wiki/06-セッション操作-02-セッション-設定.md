# セッションの設定 - sessions/set <!-- omit in toc -->

## 概要

APIを使用してセッションデータを設定します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## メソッド

```csharp
Task<ApiResponse<SetSessionResponse>> SetSessionAsync(
    SetSessionRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## パラメータ

| 引数                | 型                  | 必須 | 説明                   |
| ------------------- | ------------------- | :--: | ---------------------- |
| `request`           | `SetSessionRequest` | Yes  | リクエストモデル       |
| `timeout`           | `TimeSpan?`         |      | リクエストタイムアウト |
| `cancellationToken` | `CancellationToken` |      | キャンセルトークン     |

## 使用例

### セッションを設定

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Sessions;

var request = new SetSessionRequest
{
    Name = "MySessionKey",
    Value = "MySessionValue"
};
var result = await client.SetSessionAsync(request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine("セッションを設定しました");
}
```
