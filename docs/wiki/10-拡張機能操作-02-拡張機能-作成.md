# 拡張機能の作成 - extensions/create <!-- omit in toc -->

## 概要

APIを使用して新しい拡張機能を作成します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 制限事項

- サービス管理者権限が必要です

## メソッド

```csharp
Task<ApiResponse<CreateExtensionResponse>> CreateExtensionAsync(
    CreateExtensionRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## パラメータ

| 引数                | 型                       | 必須 | 説明                   |
| ------------------- | ------------------------ | :--: | ---------------------- |
| `request`           | `CreateExtensionRequest` | Yes  | リクエストモデル       |
| `timeout`           | `TimeSpan?`              |      | リクエストタイムアウト |
| `cancellationToken` | `CancellationToken`      |      | キャンセルトークン     |

## 使用例

### 拡張機能を作成

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Extensions;

var request = new CreateExtensionRequest
{
    ExtensionType = "Sql",
    ExtensionName = "カスタムSQL",
    ExtensionSettings = "SELECT * FROM Items",
    ExtensionDescription = "テスト用SQL拡張機能"
};

var result = await client.CreateExtensionAsync(request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine($"作成された拡張機能ID: {result.Data.Id}");
}
```
