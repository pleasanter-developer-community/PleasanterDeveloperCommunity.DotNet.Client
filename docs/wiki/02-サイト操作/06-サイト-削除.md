## 概要

APIを使用してサイトを削除します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 制限事項

- テナント管理者権限が必要です

## DeleteSiteAsync

```csharp
Task<ApiResponse<DeleteSiteResponse>> DeleteSiteAsync(
    long siteId,
    DeleteSiteRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

### パラメータ

| プロパティ#1        | #2  | 型                  | 必須 | 説明                   |
| ------------------- | --- | ------------------- | :--: | ---------------------- |
| `siteId`            |     | `long`              | Yes  | サイトID               |
| `request`           |     | `DeleteSiteRequest` | Yes  | リクエストモデル       |
| `timeout`           |     | `TimeSpan?`         |      | リクエストタイムアウト |
| `cancellationToken` |     | `CancellationToken` |      | キャンセルトークン     |

### レスポンス

| プロパティ#1 | 型        | 説明               |
| ------------ | --------- | ------------------ |
| `Id`         | `long`    | 削除されたサイトID |
| `StatusCode` | `int`     | ステータスコード   |
| `Message`    | `string?` | メッセージ         |

## 使用例

### サイトを削除

```csharp
using VehicleVision.Pleasanter.DotNet.Client.Models.Requests.Sites;

var request = new DeleteSiteRequest();
var result = await client.DeleteSiteAsync(siteId: 123, request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine("サイトを削除しました");
}
```
