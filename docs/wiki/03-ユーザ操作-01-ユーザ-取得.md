## 概要

APIを使用してユーザ一覧を取得します。

- テナント管理者権限が必要です

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 使用例

### 全ユーザを取得

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Users;

var request = new GetUsersRequest();
var result = await client.GetUsersAsync(request);

if (result.IsSuccess)
{
    foreach (var user in result.Response?.Data ?? new List<UserData>())
    {
        Console.WriteLine($"ユーザ: {user.Name} ({user.LoginId})");
    }
}
```

### フィルタを使用

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Users;

var request = new GetUsersRequest
{
    Offset = 0,
    View = new View
    {
        ColumnFilterHash = new Dictionary<string, string>
        {
            { "Disabled", "false" }
        }
    }
};

var result = await client.GetUsersAsync(request);
```
