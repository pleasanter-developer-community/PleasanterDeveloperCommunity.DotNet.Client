## 概要

APIを使用して検索インデックスを再構築します。全サイトまたは特定のサイトを対象に再構築を実行できます。

この機能を利用するには、プリザンターのパラメータ設定で `BackgroundTask.Enabled` を有効にする必要があります。

> **Note**: このAPIはプリザンター公式マニュアルには記載されていません（コントローラ単位で未記載）。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## RebuildSearchIndexesAsync

```csharp
Task<ApiResponse<RebuildSearchIndexesResponse>> RebuildSearchIndexesAsync(
    long? siteId,
    RebuildSearchIndexesRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

### パラメータ

| プロパティ#1        | #2  | 型                            | 必須 | 説明                                   |
| ------------------- | --- | ----------------------------- | :--: | -------------------------------------- |
| `siteId`            |     | `long?`                       | Yes  | サイトID（nullの場合は全サイトが対象） |
| `request`           |     | `RebuildSearchIndexesRequest` | Yes  | リクエストモデル                       |
| `timeout`           |     | `TimeSpan?`                   |      | リクエストタイムアウト                 |
| `cancellationToken` |     | `CancellationToken`           |      | キャンセルトークン                     |

### レスポンス

| プロパティ#1 | 型        | 説明             |
| ------------ | --------- | ---------------- |
| `Id`         | `long`    | ID               |
| `StatusCode` | `int`     | ステータスコード |
| `Message`    | `string?` | メッセージ       |

## 使用例

```csharp
// 全サイトの検索インデックスを再構築
var request = new RebuildSearchIndexesRequest();
var result = await client.RebuildSearchIndexesAsync(null, request);

if (result.IsSuccess)
{
    Console.WriteLine($"メッセージ: {result.Response?.Message}");
}

// 特定サイトの検索インデックスを再構築
var result2 = await client.RebuildSearchIndexesAsync(123, request);

if (result2.IsSuccess)
{
    Console.WriteLine($"メッセージ: {result2.Response?.Message}");
}
```
