# 拡張機能の更新 - extensions/{extensionId}/update <!-- omit in toc -->

## 概要

APIを使用して既存の拡張機能を更新します。

## 対応バージョン

- プリザンター 1.3.13.0以降
    - このライブラリの制約によるもの

## 制限事項

- サービス管理者権限が必要です

## メソッド

```csharp
Task<ApiResponse<UpdateExtensionResponse>> UpdateExtensionAsync(
    long extensionId,
    UpdateExtensionRequest request,
    TimeSpan? timeout = null,
    CancellationToken cancellationToken = default)
```

## パラメータ

| 引数                | 型                       | 必須 | 説明                   |
| ------------------- | ------------------------ | :--: | ---------------------- |
| `extensionId`       | `long`                   | Yes  | 拡張機能ID             |
| `request`           | `UpdateExtensionRequest` | Yes  | リクエストモデル       |
| `timeout`           | `TimeSpan?`              |      | リクエストタイムアウト |
| `cancellationToken` | `CancellationToken`      |      | キャンセルトークン     |

## 使用例

### 拡張機能を更新

```csharp
using PleasanterDeveloperCommunity.DotNet.Client.Models.Requests.Extensions;

var request = new UpdateExtensionRequest
{
    ExtensionName = "更新後の拡張機能名",
    ExtensionSettings = "SELECT Id, Title FROM Items"
};

var result = await client.UpdateExtensionAsync(extensionId: 123, request: request);

if (result.Data?.StatusCode == 200)
{
    Console.WriteLine("拡張機能を更新しました");
}
```
